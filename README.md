## Development

Requires Node.js 22.19 or newer.

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

Astro and TypeScript; static output deployed to GitHub Pages through GitHub Actions. Source components live in `src/`; public brand assets and source references live in `public/`. Logos identify their respective brands and do not imply endorsement.
